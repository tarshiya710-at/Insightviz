# InsightViz

AI-Driven Data Analytics, Quality Validation, and Automated Visualization

## Overview

InsightViz is a proposed AI-powered framework designed to transform messy real-world tabular data into reliable analytical insights and meaningful visualizations.

The system aims to identify data quality issues, assist with preprocessing, validate cleaning operations, and help users explore data through analytics and automatically generated charts.

## Problem Statement

Real-world datasets often contain missing values, duplicate records, inconsistent formats, incorrect data types, and inconsistent category labels. These issues can affect analytical results and lead to misleading visualizations.

InsightViz aims to streamline data preparation and visualization while checking whether preprocessing operations preserve the meaning of the original data.

## Objectives

- Automatically profile datasets and identify data quality issues.
- Assist with missing-value handling, duplicate detection, and data normalization.
- Validate cleaning operations using appropriate data quality checks.
- Support exploratory data analysis and statistical summaries.
- Generate suitable visualizations from cleaned data.
- Explore natural-language queries for user-friendly data analysis.

## Proposed Workflow

1. Upload a CSV or Excel dataset.
2. Profile the dataset and detect potential quality issues.
3. Recommend and apply appropriate cleaning operations.
4. Validate the cleaned dataset and report significant changes.
5. Analyze the data based on the user's question.
6. Generate visualizations and present the findings.
